Démarrer le bac à sable

Depuis la racine du dépôt, avec Docker démarré, lancer les services puis récupérer l’URL et le jeton de JupyterLab.

docker compose -f sandbox/compose.yaml up --build --wait
docker compose -f sandbox/compose.yaml exec atelier jupyter server list

Ouvrir JupyterLab sur 127.0.0.1:8888 avec le jeton affiché. Le dossier data/ contient le CSV de l’atelier.

Pour accéder à PostgreSQL avec psql, utiliser la commande suivante.

docker compose -f sandbox/compose.yaml exec postgres psql -U student -d formation
